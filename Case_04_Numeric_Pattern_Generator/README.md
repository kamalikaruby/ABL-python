# Case Study 04: Numeric Pattern Generator

## Objectives
- Use nested while loops.
- Build output text using strings and concatenation.
- Use variables and counters to control repetition.
- Validate the number of rows.

## Assumptions
- The user enters an integer from 1 to 10.
- The pattern starts at 1 and increases by one within each row.
- The pattern is printed to the console.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — steps to solve the problem
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — source code
- `test_cases.md` — test scenarios and expected outcomes
- `outputs/` — instructions and execution report

## Run the program
Open a terminal in this folder and run `python main.py`. Enter the values requested by the program.
