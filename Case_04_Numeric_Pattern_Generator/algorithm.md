# Algorithm — Case Study 04: Numeric Pattern Generator

1. Start.
2. Read the number of rows.
3. If the row count is less than 1 or greater than 10, display an invalid row count message.
4. Otherwise set the row counter to 1.
5. For each row, set the column counter to 1 and create an empty line.
6. Append each column number and a space until the column counter exceeds the row counter.
7. Print the line, increase the row counter, and repeat until all rows are printed.
8. Stop.
