# Problem Statement — Case Study 04

Read a row count and print an increasing numeric pattern. Row 1 prints 1; row 2 prints 1 2; each next row prints all integers from 1 through the row number.

## Objectives
1. Use nested while loops.
2. Build output text using strings and concatenation.
3. Use variables and counters to control repetition.
4. Validate the number of rows.

## Assumptions
- The user enters an integer from 1 to 10.
- The pattern starts at 1 and increases by one within each row.
- The pattern is printed to the console.
