# Algorithm

1. Start.
2. Set the pass mark to 40, grace limit to 5, and subject count to 5.
3. Read marks for each of the five subjects.
4. If a mark is less than 0 or greater than 100, display an error and stop processing.
5. Find how many subjects have marks below 40.
6. If exactly one subject failed and its mark is between 35 and 39, award only the marks needed to reach 40.
7. Calculate the total and percentage.
8. Check every subject mark. If all are at least 40, display PASS; otherwise display FAIL.
9. Stop.
