# Case Study 01: Examination Result and Grace-Mark Validation

## Objectives
- Read and validate marks for five subjects.
- Calculate total marks and percentage.
- Determine pass or fail status.
- Demonstrate variables, lists, loops, operators, and conditional statements.

## Assumptions
- There are five subjects, each marked out of 100.
- The pass mark is 40 in each subject.
- For this example only, up to 5 grace marks may be awarded when exactly one subject has between 35 and 39 marks. Confirm your college's actual grace-mark rules with your faculty.

## Files in this folder
- `problem_statement.md` — problem and objectives
- `algorithm.md` — step-by-step algorithm
- `flowchart.md` — text flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — executable Python program
- `test_cases.md` — sample tests and expected outputs

## How to run
Run `python main.py` in a terminal from this folder.

## Conclusion
This case study uses basic Python lists, loops, arithmetic, and if-statements to process marks and determine a student's result.
