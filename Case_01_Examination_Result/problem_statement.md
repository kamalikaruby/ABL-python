# Problem Statement

Write a Python program that accepts marks for five subjects, validates that every mark is between 0 and 100, calculates the total and percentage, and determines whether the student passes every subject. For demonstration, the program may apply a limited grace-mark rule when exactly one subject is just below the pass mark.

## Objectives
1. Practice input and output.
2. Use variables, lists, loops, and conditional statements.
3. Calculate total marks and percentage.
4. Display a clear PASS or FAIL result.

## Assumptions
- Five subjects, each out of 100.
- Minimum passing mark is 40 in each subject.
- Demonstration grace policy: add enough marks to reach 40 only when exactly one subject is in the range 35–39; maximum grace is 5 marks.
- This grace policy is illustrative, not a claim about the college's official policy.
