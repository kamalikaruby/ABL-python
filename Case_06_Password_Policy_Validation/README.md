# Case Study 06: Password Policy Validation

## Objectives
- Traverse a string character by character.
- Use comparisons and Boolean variables.
- Count characters using a loop.
- Display individual policy checks and an overall result.

## Assumptions
- The password is checked exactly as entered; case matters.
- A valid password must be at least 8 characters and contain uppercase, lowercase, and numeric characters.
- This classroom check is not a complete security review.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — solution steps
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — Python program
- `test_cases.md` — test scenarios and expected outcomes
- `outputs/` — execution evidence instructions

## Run
Open a terminal in this folder and run `python main.py`.
