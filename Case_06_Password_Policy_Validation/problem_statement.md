# Problem Statement — Case Study 06

Read a password and check whether it contains at least eight characters, at least one uppercase letter, at least one lowercase letter, and at least one digit. Display each check and the overall status.

## Objectives
1. Traverse a string character by character.
2. Use comparisons and Boolean variables.
3. Count characters using a loop.
4. Display individual policy checks and an overall result.

## Assumptions
- The password is checked exactly as entered; case matters.
- A valid password must be at least 8 characters and contain uppercase, lowercase, and numeric characters.
- This classroom check is not a complete security review.
