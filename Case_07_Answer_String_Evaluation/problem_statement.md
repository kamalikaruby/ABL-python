# Problem Statement — Case Study 07

Evaluate a student's answers to five multiple-choice questions by comparing each entered answer with a fixed answer key. Validate that each response is one of A, B, C, or D, then calculate the score and percentage.

## Objectives
1. Use strings to represent choices.
2. Store student answers and the answer key in lists.
3. Compare strings with conditional statements.
4. Calculate score and percentage using arithmetic.

## Assumptions
- There are five questions worth one mark each.
- Illustrative answer key: A, C, B, D, A.
- Answers must be entered as uppercase A, B, C, or D.
- No negative marking is applied.
