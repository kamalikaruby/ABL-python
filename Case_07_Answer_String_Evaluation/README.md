# Case Study 07: String-Based Examination Answer Evaluation

## Objectives
- Use strings to represent choices.
- Store student answers and the answer key in lists.
- Compare strings with conditional statements.
- Calculate score and percentage using arithmetic.

## Assumptions
- There are five questions worth one mark each.
- Illustrative answer key: A, C, B, D, A.
- Answers must be entered as uppercase A, B, C, or D.
- No negative marking is applied.
