# Algorithm — Case Study 09: Student Marks Matrix Analysis

1. Create an empty nested list for marks.
2. For each student, read three subject marks and validate each mark.
3. If a mark is invalid, display an error and do not calculate summary results.
4. For each student row, calculate and display its total.
5. For each subject column, add marks from all students and divide by three.
6. Display subject averages.
