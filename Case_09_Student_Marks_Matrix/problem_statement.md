# Problem Statement — Case Study 09

Enter marks for three students across three subjects using a nested list. Validate each mark, calculate the total for each student, and calculate the average mark for each subject.

## Objectives
1. Represent tabular data using a nested list.
2. Use nested while loops to read and process marks.
3. Calculate row totals and column averages.
4. Validate marks with conditional statements.

## Assumptions
- There are three students and three subjects.
- Each mark is an integer from 0 to 100.
- Totals and averages are calculated only when all marks are valid.
