# Case Study 09: Student Marks Matrix Analysis

## Objectives
- Represent tabular data using a nested list.
- Use nested while loops to read and process marks.
- Calculate row totals and column averages.
- Validate marks with conditional statements.

## Assumptions
- There are three students and three subjects.
- Each mark is an integer from 0 to 100.
- Totals and averages are calculated only when all marks are valid.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — solution steps
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — Python program
- `test_cases.md` — test scenarios and expected outcomes
- `outputs/` — execution evidence instructions

## Run
Open a terminal in this folder and run `python main.py`.
