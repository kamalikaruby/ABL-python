# Problem Statement — Case Study 03

Accept marks from four assessments, validate each mark, calculate the average, and compare the last assessment with the first to identify whether performance improved, declined, or remained the same.

## Objectives
1. Store assessment scores in a list.
2. Validate scores using conditional statements.
3. Calculate total and average using a loop.
4. Compare the first and last scores to identify a trend.

## Assumptions
- Exactly four assessments are entered.
- Each mark is an integer from 0 to 100.
- Trend means comparison of the last mark with the first mark only.
