# Algorithm — Case Study 03: Student Performance Trend Analysis

1. Read four assessment marks and validate each as 0 to 100.
2. Store each valid mark in a list.
3. If any mark is invalid, display an error and do not produce a summary.
4. Use a loop to calculate total and average.
5. Compare the last mark with the first mark.
6. Display marks, total, average, and trend.
