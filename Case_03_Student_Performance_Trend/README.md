# Case Study 03: Student Performance Trend Analysis

## Objectives
- Store assessment scores in a list.
- Validate scores using conditional statements.
- Calculate total and average using a loop.
- Compare the first and last scores to identify a trend.

## Assumptions
- Exactly four assessments are entered.
- Each mark is an integer from 0 to 100.
- Trend means comparison of the last mark with the first mark only.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — steps to solve the problem
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — source code
- `test_cases.md` — test scenarios and expected outcomes
