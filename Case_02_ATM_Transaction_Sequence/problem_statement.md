# Problem Statement — Case Study 02

Create a simple ATM program that processes a chosen number of deposits and withdrawals. It must update the balance, reject non-positive amounts, prevent withdrawals that exceed the balance, and show a transaction history.

## Objectives
1. Use variables to store account balance and transaction count.
2. Use conditions to choose deposit or withdrawal processing.
3. Use a while loop to process transactions in sequence.
4. Use a list to store transaction history.

## Assumptions
- Starting balance is ₹1,000 for demonstration.
- The user selects 1 to 10 transactions.
- Transaction type must be entered as D for deposit or W for withdrawal.
- Amounts must be positive integers; withdrawals cannot exceed the current balance.
