# Algorithm — Case Study 02: ATM Transaction Sequence Simulation

1. Start with a balance of 1000.
2. Read the number of transactions and check that it is from 1 to 10.
3. Repeat each transaction while input remains valid.
4. Read transaction type and amount.
5. For a valid deposit, add the amount; for a valid withdrawal, subtract only if the amount is positive and no greater than the balance.
6. Record successful transactions or rejection messages.
7. Display transaction history and final balance.
