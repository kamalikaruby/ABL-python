# Case Study 02: ATM Transaction Sequence Simulation

## Objectives
- Use variables to store account balance and transaction count.
- Use conditions to choose deposit or withdrawal processing.
- Use a while loop to process transactions in sequence.
- Use a list to store transaction history.

## Assumptions
- Starting balance is ₹1,000 for demonstration.
- The user selects 1 to 10 transactions.
- Transaction type must be entered as D for deposit or W for withdrawal.
- Amounts must be positive integers; withdrawals cannot exceed the current balance.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — steps to solve the problem
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic

Open a terminal in this folder and run `python main.py`. Enter the values requested by the program.
