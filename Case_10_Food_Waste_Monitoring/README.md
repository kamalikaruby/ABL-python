# Case Study 10: Food Waste Monitoring System

## Objectives
- Store daily quantities in lists.
- Validate prepared and leftover quantities.
- Use loops and arithmetic to calculate totals and percentage.
- Compare waste percentage with a target using a condition.

## Assumptions
- The program records five days.
- Quantities are non-negative integer units; prepared quantity must be greater than zero each day.
- Leftover quantity cannot exceed prepared quantity.
- The 10% waste target is illustrative for this classroom exercise, not an official standard.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — solution steps
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — Python program
- `test_cases.md` — test scenarios and expected outcomes

## Run
Open a terminal in this folder and run `python main.py`.
