# Case Study 08: Text Compression Using Character Runs

## Objectives
- Process a string character by character.
- Track the current character and repetition count using variables.
- Use if-else statements to detect character changes.
- Build a result string using concatenation.

## Assumptions
- This is a learning example, not a production compression format.
- Each run includes its count, including count one.
- Spaces and punctuation are treated as characters.

## Files
- `problem_statement.md` — problem, objectives, assumptions
- `algorithm.md` — solution steps
- `flowchart.md` — Mermaid flowchart
- `pseudocode.md` — language-independent logic
- `main.py` — Python program
- `test_cases.md` — test scenarios and expected outcomes
