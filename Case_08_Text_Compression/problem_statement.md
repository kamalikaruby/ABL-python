# Problem Statement — Case Study 08

Create a simple run-length representation of text by replacing each consecutive group of the same character with the character followed by its repetition count. For example, aaabbc becomes a3b2c1.

## Objectives
1. Process a string character by character.
2. Track the current character and repetition count using variables.
3. Use if-else statements to detect character changes.
4. Build a result string using concatenation.

## Assumptions
- This is a learning example, not a production compression format.
- Each run includes its count, including count one.
- Spaces and punctuation are treated as characters.
