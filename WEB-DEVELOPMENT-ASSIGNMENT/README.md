# Web Development Activity-Based Learning

Three selected case studies from the assignment:
1. Case Study 1 – Personal Portfolio Website
2. Case Study 6 – Online Shopping Website
3. Case Study 28 – User Registration and Login Interface

## Folders
- Project-1-Personal-Portfolio
- Project-2-Online-Shopping
- Project-3-Registration-Login

Each folder contains an index.html file and a style.css file.

## Run the websites
Open a project folder in Visual Studio Code and open index.html. Double-click index.html to run it in a browser, or use the VS Code Live Server extension.

## Notes
Replace the sample portfolio and contact details with your own. Shopping products and prices are examples. These are front-end learning projects: shopping buttons do not place orders, and the registration/login forms provide browser-side validation only. Secure authentication requires a backend service.
