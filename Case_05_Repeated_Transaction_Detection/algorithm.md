# Algorithm — Case Study 05: Repeated Transaction Detection

1. Read and validate the transaction count from 1 to 10.
2. Read positive transaction amounts into a list.
3. For each amount, count matching values using an inner loop.
4. Check whether the value is already in the repeated list.
5. Store each repeated value once.
6. Display the input list and repeated values, or state that no repeats were found.
