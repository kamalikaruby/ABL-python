# Problem Statement — Case Study 05

Accept a list of transaction amounts and identify which amounts occur more than once. Print each repeated amount only once, even if it appears three or more times.

## Objectives
1. Store transaction amounts in a list.
2. Use nested loops to compare values and count matches.
3. Use a second list to remember repeated amounts already found.
4. Apply conditions to avoid printing a duplicate twice.

## Assumptions
- The entry count must be from 1 to 10.
- Transaction amounts must be positive integers.
- Equal amounts are treated as repeats for this classroom example; equal amounts alone do not prove fraud.
